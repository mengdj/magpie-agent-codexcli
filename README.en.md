# magpie-agent-codexcli

#### Description
magpie-agent-codex-cli 是一个把 Codex CLI 接入 magpie 的 Agent 插件。装上后，magpie 的 Agent 页会多出一行 Codex CLI，你可以在里面像选内置代理一样挑选模型，然后在终端用 codex-magpie 启动，Codex 的请求就会经由 magpie 网关，走你已经登录的订阅
